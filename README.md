# Equity Market Analysis

Python project analysing historical Apple (AAPL) stock market data from 2020–2025.

## Project Overview

This project uses Python to analyse historical equity market data and investigate price movements and market risk.

## Analysis Performed

- Downloaded historical Apple stock price data using yfinance
- Calculated daily percentage returns
- Calculated daily and annualised volatility
- Visualised the distribution of daily returns
- Calculated 50-day and 200-day moving averages
- Identified moving-average crossover signals

## Technologies Used

- Python
- pandas
- yfinance
- matplotlib

## Key Concepts

Daily returns, volatility, return distributions, moving averages and quantitative trading signals.
